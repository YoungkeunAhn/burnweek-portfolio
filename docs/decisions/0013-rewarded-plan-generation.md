# ADR-0013: 미니앱 플랜 생성 — 주 1회 무료 + 보상형 광고

> **상태:** Accepted (사용자 지시, 2026-09-10)
> **대체 범위:** D8의 무료 MVP·주간 생성 상한을 토스 미니앱에 한해 대체한다. 동결된 Flutter 경로는 유지한다.

## 결정

- 검증된 토스 로그인 uid별로 한국 시간 월요일 00:00부터 주 1회 무료 생성한다. 요청 본문의 사용자·주차 값으로 사용 기회를 초기화하지 않는다.
- 추가 생성은 사용자가 보상형 광고를 선택해 시청하면 1회 제공한다. 주 3회 상한은 없앤다. 기존 시도 횟수는 새 정책에 이월하지 않아 전환 후 첫 생성은 무료다.
- 광고 전에 보상 내용과 수량을 안내한다. 기존 플랜 열람·운동 기록·수동 편집에는 광고를 요구하지 않는다.
- `userEarnedReward` 이벤트만 보상을 요청한다. 클릭·닫기·광고 로딩 실패는 보상이 아니다. 서버는 계정에 묶인 일회용 시청 요청을 발급하고 중복 지급을 막는다.
- 생성 접수와 사용 기회 예약을 Firestore 트랜잭션으로 처리한다. 계정당 진행 중인 잡은 1개이고 재요청은 같은 잡을 돌려준다. 생성·저장·큐 접수 실패 시 무료 기회 또는 광고 보상을 복구한다. 20분간 끝나지 않은 잡은 다음 조회/접수 시 실패로 정리하며 늦은 결과 저장을 막는다.
- 광고 보상은 주가 바뀌거나 앱을 닫아도 유지한다. 계정 삭제 시 보상·시청 요청도 삭제하고 이전 연결의 응답을 거부한다.

## 배포 전환

2026-09-10 09:55에 출시된 기존 버전 `20260909-19`에는 광고 화면이 없다. 새 미니앱의 정식 출시와 광고 그룹 준비가 끝난 뒤 서버 환경변수 `TOSS_REWARDED_GENERATION_ENABLED=true`로 광고 정책을 활성화한다. 그룹 ID 미설정 또는 활성화 전에는 토스의 기존 주 3회 한도와 광고 요구를 모두 적용하지 않는다. 진행 중 잡 중복 방지·계정 분리는 계속 유지하며 전환 기간 무료 사용 주는 기록한다. 활성화 뒤에는 그 주의 추가 생성부터 보상형 정책을 적용한다.

**활성화 확인 완료 2026-09-23.** 서버 플래그를 켠 뒤(2026-09-19) 같은 주 두 번째 「추천 플랜 생성」에 보상형 광고가 뜨는 것을 사용자가 실기기에서 확인했다(테스트 번들 `20260923-48`) — 백로그 053 은 이 줄로 대체하고 삭제한다.

## 저장 및 검증 범위

`generation_access/{uid}`에 무료 사용 주, 보상 잔여 횟수, 진행 중인 예약, 최근 시청 요청만 저장한다. Firestore가 정본이며 클라이언트 저장값으로 권한을 판단하지 않는다. 생성 API 계약을 따른다.

SDK 3.0.4 공개 API의 `showFullScreenAd` 옵션은 `adGroupId`이며, 보상 콜백에 서버 검증용 서명이나 SSV 설정은 제공되지 않는다. 일회용 요청은 계정 혼동·재전송을 막지만 변조한 클라이언트의 허위 시청을 증명할 수는 없다. 서버 검증을 지원하는 공식 인터페이스가 제공되면 그 경로로 대체한다. LLM 키·수치 생성·워커 동시 실행 수 제한은 기존 규약을 따른다.
