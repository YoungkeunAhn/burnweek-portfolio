# ADR-0020: YouTube 참고 영상의 별도 닫기·열기 버튼 제거

## Status

Accepted (2026-10-08, 사용자 요청). [ADR-0019](./0019-youtube-reference-preview-on-entry.md)의 직접 닫기·숨김 뒤 다시 열기 규칙을 대체한다.

## Context

상세 진입 시 바로 표시하는 플레이어에는 별도 닫기·다시 열기 버튼이 필요하지 않다.

## Decision

정상 상태에서는 공식 YouTube 플레이어만 표시하고 앱의 닫기·열기 버튼은 두지 않는다. 로딩 실패 때만 다시 불러오기 버튼을 제공한다. 화면이 숨겨지면 재생을 일시 정지하고 플레이어를 유지한다. 복귀 시 다시 재생하거나 다시 불러오지 않는다. 종목 변경·상세 종료 시에는 이전 플레이어를 제거한다. ADR-0019의 즉시 표시·자동 재생 금지 규칙은 유지한다.

## Consequences

상세 화면과 백그라운드 복귀 모두 별도 열기 동작이 없다. `miniapp/exercise-youtube-check.mjs`에서 10종 × 360/390px 추가 버튼 없음·실패 재시도·숨김 일시 정지·복귀 유지·종목 변경/종료를 검증한다.
