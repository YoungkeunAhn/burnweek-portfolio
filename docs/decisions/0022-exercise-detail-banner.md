# ADR-0022: 운동 상세 페이지 하단 배너

## Status

Accepted (2026-10-08, [D96](./mvp-decision-log.md#d96)). [ADR-0021](./0021-exercise-detail-page.md)의 운동 상세 광고 제외 부분을 대체한다.

## Context

사용자가 독립 페이지로 바뀐 운동 상세의 하단에도 배너 광고를 요청했다. 페이지는 기존 오버레이와 달리 본문 끝에 광고를 배치할 수 있다.

## Decision

공통 운동 상세의 운동 설명 뒤, 스크롤 본문 맨 끝에 기존 `AdBanner`를 하나 표시한다. D91·R13의 일반 규칙을 적용한다: 고정하지 않고 앞 내용과 24px 이상 간격을 둔다. 광고 없음·실패·미지원 환경에서는 자리를 접는다. 출발 화면은 계속 `hidden`으로 유지해 그 화면의 배너가 함께 노출되지 않게 한다. 탭바 숨김·뒤로가기 복원·미디어 수명 규칙은 ADR-0021을 유지한다.

## Consequences

배너 대상은 탭 5개와 하위 페이지 6개로 총 11화면이다. 실제 시트·다이얼로그에는 배너를 넣지 않는다. `miniapp/check.mjs`에서 화면별 수량·배치를, `miniapp/startup-check.mjs`에서 360·390px 본문 끝 배치·24px 간격·단일 노출·복귀 입력 보존을 검증한다.
