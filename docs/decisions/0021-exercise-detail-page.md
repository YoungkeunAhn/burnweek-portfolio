# ADR-0021: 운동 상세를 독립 페이지로 전환

## Status

Accepted (2026-10-08, [D95](./mvp-decision-log.md#d95)). D91의 운동 상세를 `.picker` 오버레이로 다루던 부분을 대체한다. 상세의 광고 제외와 D30의 `[← 제목]` 규칙은 유지한다.

## Context

운동 상세가 거의 전체 화면을 덮으면서 아래 탭바와 출발 화면이 남아 있어 사용자가 불편함을 느꼈다. 운동 목록과 운동 중 화면 모두 같은 상세 페이지로 이동해야 한다.

## Decision

운동 상세는 App이 소유하는 별도 `main`으로 표시한다. 기존 앱의 React 상태 기반 탐색과 토스 뒤로가기 스택을 사용한다. 고정 오버레이·모달 역할·내부 스크롤을 없애고 문서 전체가 스크롤한다. 제목과 뒤로 버튼은 위에 유지한다. 상세에는 하단 탭바와 광고를 표시하지 않는다.

출발 화면은 마운트를 유지하며 `hidden`으로 화면·접근성 트리·탭 순서에서 제외한다. 상세에 들어갈 때 맨 위와 상세 영역으로 포커스를 이동한다. 상단 화살표와 토스 뒤로가기는 출발 화면의 스크롤·포커스를 복원한다. 운동 기록의 선택 종목·입력·휴식 상태는 계속 유지한다. 목록은 복귀 시 정렬을 유지하고 검색·분류를 바꿀 때 최신 최근 목록을 반영한다.

3D 동작 자료와 YouTube 플레이어의 재생 규칙은 유지한다. 상세에서 나가면 해당 미디어를 언마운트해 재생을 종료한다.

## Consequences

상세 화면을 운동 목록과 실행 화면에서 동일하게 이용한다. `miniapp/startup-check.mjs`에서 360·390px 페이지 배치·문서 스크롤·탭바 숨김·두 뒤로가기 경로·목록 위치와 포커스·운동 입력 보존을 검증한다. 미디어 재생 수명은 기존 브라우저 검사로 확인한다.
