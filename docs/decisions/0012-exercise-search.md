# ADR-0012: 운동 검색의 부위 유지·한글 검색·후보 더 보기

- **Status:** Accepted (사용자 요청, 2026-09-09)
- **Date:** 2026-09-09
- **Supersedes:** [D25](./mvp-decision-log.md)의 `q`가 `muscle`을 무시한다는 규칙. 장비·금기 규칙은 유지한다.

## Context

부위를 선택하고 검색하면 부위가 풀린다는 실기기 피드백이 있었다. `EZ바 컬`은 카탈로그에 있지만 `이지바`로 검색되지 않고, 이름순 40개 밖에 있어 훑기로도 고를 수 없었다. 사용자가 `es-hangul` 기반 개선과 같은 유형의 영문 약어 별칭 처리를 요청했다.

## Decision

- 검색어와 선택 부위를 함께 유지한다. `q`와 `muscle`이 함께 오면 선택한 근육 안에서 검색한다. 부위를 바꿔도 검색어는 유지하며, 전체 부위로 돌아가면 검색 범위만 넓힌다.
- 검색은 기존처럼 프로필 장비를 넘어 찾을 수 있지만 부상 금기·유산소·이미 있는 종목·교체 대상 제외를 유지한다. 명시한 근육은 검색 중에도 검증한다.
- `es-hangul`의 초성 추출·자모 분해로 초성과 입력 중인 글자를 검색한다. 기존의 공백 단위 OR 검색을 유지하고 대소문자·띄어쓰기·하이픈·밑줄을 정규화한다.
- 카탈로그의 실제 영문 약어를 기준으로 `EZ바/이지바`, `T바/티바`, `V바/브이바`, `JM/제이엠`, `SMR/에스엠알`을 검색 별칭으로 처리한다. 종목 ID와 운동 의미는 바꾸지 않는다. `이지바 바벨컬`도 `EZ바 컬`로 찾을 수 있다.
- 화면과 서버가 같은 검색 함수를 사용한다. 한 번의 후보 응답은 기본 40개이며 `limit`(1–1000)으로 더 요청하고, `total`로 실제 결과 수를 제공한다. 화면의 “더 보기”는 40개씩 늘려 전체 후보를 고를 수 있게 한다.

## Consequences

검색어가 있어도 켜진 부위 칩과 결과 범위가 일치한다. 구버전 클라이언트는 기본 40개와 기존 필드를 계속 사용한다. 새 클라이언트보다 백엔드를 먼저 배포해야 하며, 늦은 검색·더 보기 응답은 현재 조건을 덮어쓰면 안 된다.
