# ADR-0023: 입력을 유지하는 세트 행과 화면 정보 위계

## Status

Accepted (2026-10-13, [D98](./mvp-decision-log.md#d98)). 사용자가 UI 비교 시안을 승인하고 실제 구현과 Aside 검증을 요청했다.

## Context

중복 설명과 겹친 테두리가 입력을 밀어내고, 세트 편집 아코디언이 화면 높이를 바꾸면서 스크롤·키보드 사용을 방해했다. 정보량을 줄이려 대시보드 기능을 숨기는 방식은 사용자가 거절했다.

## Decision

- 세트 행은 무게·횟수·휴식을 항상 입력할 수 있는 한 줄이다. 입력 요소를 유지하고 Enter로 다음 칸에 이동한다. lb를 입력하는 동안 문자열을 반올림하지 않는다. 완료와 통증은 독립 상태이며 통증·삭제는 행의 더보기에서 조작한다. 통증 표시는 행에 남기고 중단 안내는 계속 보인다. 이전·최고 기록은 ‘기록 비교’로 연다.
- 일괄적용은 열린 날짜의 해당 종목 세트만 바꾼다. 완료 세트를 포함하고 제외한 세트는 보존한다. 적용 범위 선택·대상 세트 나열·메모 입력은 제거한다. 주간 계획 편집 API를 호출하지 않는다. 메모·교체·지난 기록 불러오기는 기존 개별 진입점을 유지한다.
- 주간 달력은 구분선으로 연결한다. 날짜 아래 ‘완료’는 파란색 굵은 글씨, ‘오늘’은 검정 계열 글씨다. 운동 추가·날짜 이동·순서 변경을 목록 위에 두고, 운동 제목 옆 정보 버튼과 편집 오른쪽 삭제 버튼을 제공한다. 총 세트·볼륨의 기존 계산과 표시를 유지한다.
- 계획 편집은 네이티브 모달로 요일·종목·입력·저장·취소를 명확히 구분한다. 횟수 의도 선택은 저장 전까지 서버를 바꾸지 않는다. 저장 오류는 화면 안에서 보여주며 입력을 유지한다. 유산소 종류별 입력은 그대로 보존한다. 근력 수치와 횟수 의도는 기존 API를 순차 호출하고 실패한 단계부터 재시도한다.
- 체중은 날짜·체중·저장을 먼저 배치하고 선택 입력은 펼침으로 둔다. 같은 날짜의 기존 값을 불러오며 숨긴 선택 항목도 보존한다. 차트는 체중·체지방·골격근 중 하나를 파란색으로 표시하며 시간 간격과 항목별 축을 유지한다. 목표는 별도 창에서 저장한다. 최근 기록에서 수정·삭제할 수 있다.
- 대시보드는 오늘 운동 → 월 달력 → 주간 진행 → 꾸준함·성장 → 최근 기록 → 주간 리뷰 → 부위별 비중 → 광고 순서다. 기존 구획과 진입 기능을 접거나 제거하지 않는다. 날짜 선택과 기록 조회의 기존 동작도 유지한다.
- 설정은 기본정보 요약에서 전체 정보를 열고, 운동 무게 단위·알림·초기화를 묶는다. 재설정과 전체 삭제의 영향은 실제 동작 전 확인에서 알린다. 의료 면책 전문은 광고 뒤 최하단에 유지한다. 대시보드와 체중 아이콘을 구별하고 중앙 탭은 ‘플랜’으로 표시한다.

## Supersedes

D39-3의 일괄적용 범위, D39-4의 상시 통증 버튼, D61의 기록 비교 상시 노출, D66의 세트 아코디언, D69·D90의 홈 배치 순서, D74의 중앙 탭 이름을 위 범위에서 대체한다. D91·D96의 광고 배치·실패 처리, D95의 운동 상세 복귀, INV-1·INV-6과 기존 저장 계약은 유지한다.

## Validation

`miniapp/ui-check.mjs`는 360·390px에서 편집 취소·저장 실패 재시도, 입력 위치 유지, 완료 세트 일괄적용의 계획 비변경, 체중 선택값 보존, 상세 왕복, 대시보드 전체 구획과 광고를 확인한다. 기존 순수함수·세션·시작·휴식 검사를 함께 실행한다. Aside에서는 실제 앱 UI를 조작하고 결과를 조사 폴더에 남긴다. 브라우저 검증으로 물리 기기의 소프트 키보드 동작을 확인했다고 주장하지 않는다.
