# ADR-0024: 주간 플랜·운동 기록 시안 정합

## Status

Accepted (2026-10-13, [D99](./mvp-decision-log.md#d99)). 사용자가 테스트 번들에서 확인한 시안과의 차이를 수정하고 Aside·Claude 교차검증을 요청했다.

## Context

[ADR-0023](./0023-ui-input-and-information-hierarchy.md) 구현에서 예정일 표시가 빠지고 선택 날짜의 왼쪽 선이 흐려졌다. 운동 줄의 진입 범위가 제목으로 좁아졌고, 기록 화면에는 하루 분할명이 개별 종목 부위처럼 표시됐다. 상단 배치도 승인 시안과 달랐다.

## Decision

- 플랜 머리는 ‘플랜’과 관리 메뉴, 주 기간·분할, 달력 순서다. 미선택 날짜는 흰색, 선택 날짜 양옆은 파란 구분선이다. 운동이 있는 날에는 완료 여부와 별개로 점을 표시한다. 완료는 파란색 굵게, 오늘은 검정으로 유지한다.
- 날짜 아래 종목 수·예상 시간과 날짜 변경·순서 변경·운동 추가를 표시한다. 번호가 붙은 운동 줄 전체가 기록 화면을 열며, 정보·편집·삭제 버튼은 독립 동작이다. 순서 변경 중에는 기록 진입을 잠근다. 총 세트·볼륨 계산은 바꾸지 않는다. 첫 주 상세 안내와 플랜 생성은 각각 ‘시작 안내’와 ‘플랜 관리’에서 연다.
- 기록 머리는 뒤로·운동 기록·전체 종목 수, 운동 이름·요일·카탈로그 주동근, 짧은 진행 사유 순서다. ‘AI 생성 플랜’ 표시는 제거하되 저장된 출처 값은 보존한다. 하루 분할명은 개별 종목 부위에 사용하지 않는다.
- 진행 사유는 ‘목표 달성 · 증량’, ‘횟수 미달 · 감량’, ‘통증 기록 · 종목 교체 권장’처럼 원인과 조치로 표시한다. 기존 수치와 단위는 유지한다. 운동 상세·교체는 종목 메뉴, 이전·다음 종목은 입력 아래에서 연다. 기록 비교·일괄적용 줄은 근력에만 표시한다.
- 숫자 입력 중에는 문자열과 포커스를 유지하고, 입력 칸을 떠나면 정규화한 저장값을 표시한다. 휴식의 기존 0–600초 제한은 유지한다. 광고·통증 안내·완료 동작과 기록 저장 계약은 보존한다.

## Supersedes

D54 ①의 AI 출처 표시, D50의 이전·다음 종목 상단 배치, D74의 화면 제목을 위 범위에서 대체한다. ADR-0023의 정보 위계를 구체화하며 수치 처방·기록·광고의 계약을 바꾸지 않는다.

## Validation

360·390px 브라우저 검사에서 예정일·선택선·줄 진입·개별 버튼·입력 안정성·휴식 정규화·와이드 그립 랫풀다운의 ‘등’ 표기를 확인한다. Aside 직접 조작과 독립 Claude 검토 결과는 보완 검증 기록에 남긴다. 토스 실기기 키보드는 별도 확인한다.
