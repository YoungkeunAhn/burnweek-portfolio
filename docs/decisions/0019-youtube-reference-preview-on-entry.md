# ADR-0019: 운동 상세 진입 시 YouTube 참고 플레이어 표시

## Status

Accepted (2026-10-08, 사용자 요청). [D94](./mvp-decision-log.md#d94)의 최초 버튼 클릭 후 로딩 규칙을 대체한다.

## Context

운동 상세에서 참고 영상이 버튼 뒤에 숨겨져 있어, 사용자가 플레이어를 바로 볼 수 있도록 변경을 요청했다.

## Decision

참고 영상이 있는 10종의 상세 화면에 진입하면 공식 API와 iframe을 불러와 플레이어를 표시한다. 종목을 바꾸면 이전 플레이어를 제거하고 새 종목의 플레이어를 표시한다. 자동 재생은 끄고 YouTube의 재생 버튼으로 시작한다. 직접 닫기·화면 숨김 뒤에는 다시 열기 버튼을 제공하며, 오류 때에는 다시 불러오기를 제공한다. D94의 영상 선정·최소 크기·오류 처리·상세 종료 규칙은 유지한다.

## Consequences

상세 진입 시 YouTube 네트워크 요청이 발생하며 플레이어 로딩 상태를 표시한다. 운동 기록과 기존 자세 자료는 계속 사용할 수 있다. `miniapp/exercise-youtube-check.mjs`에서 10종 × 360/390px 즉시 표시·자동 재생 금지·종목 변경·오류 복구·숨김/종료를 검증한다. 토스 실기기 재생 확인은 별도다.
